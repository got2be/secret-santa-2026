# 🎅 Таємний Санта

Статичний сайт для жеребкування «Таємного Санти». Пари згенеровано випадково
(ніхто не дарує сам собі) та зашифровано (AES-256-GCM, ключ виводиться через
PBKDF2 з імені + особистого PIN). У вихідному коді сторінки пар немає у відкритому
вигляді — побачити свій результат можна лише зі своїм PIN.

Перегенерувати: `node build.js` (виведе нові PIN у консоль; у файли вони не пишуться).
